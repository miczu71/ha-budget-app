# Loga banków

Pliki pobrane z faviconów oficjalnych stron banków (2026-11-02) na wyraźną prośbę właściciela panelu.
Loga są znakami towarowymi swoich właścicieli; w panelu służą wyłącznie do oznaczenia banku przy jego
nazwie. Pliki ICO/PNG (rozmiar ≤ 64 px) są opakowane w SVG (`<image>` z data URI), pliki
`vwbank.svg` i `pko.svg` to oryginalne SVG faviconów.
