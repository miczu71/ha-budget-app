# Loga sieci handlowych

Pliki pobrane 2026-11-19 z oficjalnych stron sieci, na potrzeby oznaczenia sieci przy paragonie w karcie
transakcji (Lidl i Biedronka). Loga są znakami towarowymi swoich właścicieli; w panelu służą wyłącznie do
oznaczenia sieci przy jej paragonie, jak loga banków.
