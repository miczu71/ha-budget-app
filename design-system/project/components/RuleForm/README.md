Formularz nowej reguły (`form.card.rule-form`): warunki „Gdy”, filtry dodatkowe i wynik „Wtedy”.

Nagłówki `h2` „Gdy” i „Wtedy” dzielą formularz. Każdy warunek to wiersz `div.cond` (pole, operator, wartość); pierwszy jest wymagany, dwa kolejne opcjonalne, wszystkie muszą być spełnione. `div.inline` grupuje filtry (konto, typ, kierunek, kwota od–do) i wynik (kategoria, nazwa sprzedawcy). Stopka `p.actions-row`: „Zapisz i przelicz” oraz link Anuluj. Pod formularzem karta „Podgląd” pokazuje, ile transakcji reguła złapie.

- Pola mają cel dotyku 44 px; wiersz `cond` zawija się na telefonie.
