Lista wierszy (`ul.rows`): data, tytuł z opcjonalną plakietką i kwota; cały wiersz jest linkiem.

Używana w Podsumowaniu, Cyklicznych i prognozie „Do wypłaty”. `a.row` układa kolumny `row-date`, `row-title` i `row-amount`; drugi wiersz kwoty (`row-bal`) pokazuje saldo. `li.fc-low-row` zaznacza wiersz najniższego punktu na `surface-2`.

- Kwota wydatku jest neutralna (Ink); kolor `pos` ma tylko wpływ.
- Wiersz ma co najmniej 44 px wysokości.
