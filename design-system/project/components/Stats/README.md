Kafelki statystyk (`div.stats` z `div.stat`): etykieta, duża wartość i zmiana względem poprzedniego okresu.

Trzy kolumny. `stat-value` to Serif Display 18 px, waga 600, `tabular-nums`. Zmiana `span.chg` ma kierunek strzałki (Lucide) i kolor znaczeniowy: `good` (`pos`) albo `bad` (`neg`); `lower_is_better` odwraca znaczenie dla wydatków. Podpis pod kafelkami mówi wprost, z czym porównujemy.
