Słupki wpływów i wydatków z ostatnich 12 miesięcy (`svg.bars`) z legendą `p.bars-legend`.

Para słupków na miesiąc, wspólna skala z „ładnym” maksimum (`nice_ceiling`). Wpływy mają kolor `bar-income` (`pos`), wydatki `bar-expense` (Ink). Słupek jest linkiem do miesiąca (obszar `hit` ≥ 24 px szerokości), wybrany miesiąc ma klasę `sel`, bieżący niepełny `partial`. Etykiety osi pod linią siatki; opis w `<title>` i `aria-label`.

- Kwota wydatku jest neutralna, kolor ma tylko wpływ.
- Konsument dostarcza wiersze miesięcy (`month_bars`).
