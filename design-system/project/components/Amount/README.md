Kwoty: duża liczba bohater (`hero-amount`), `big` i kwoty w tabelach (`num`, `pos`, `neg`).

Liczby są bohaterem ekranu: Serif Display, `lining-nums tabular-nums`, separator tysięcy U+202F. `hero-amount` ma 40–56 px (clamp). Kwota wydatku w wierszu jest neutralna; kolor `pos` mają wpływy, `neg` przekroczenia. Strzałki zmiany: `span.chg` (patrz Stats).

- Format: „2 800,00 zł”, minus jako „−” (U+2212).
