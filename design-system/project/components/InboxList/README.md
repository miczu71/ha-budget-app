Lista „Do decyzji” (`ul.inbox`): sprawy wymagające uwagi, każda jako link z tytułem i licznikiem.

`li.inbox-item` ma wariant `warn` (wymaga działania) albo `info`; `inbox-title` to opis, `inbox-count` liczba (zbiorczo lub 1). Ta sama lista zasila dzwonek `a.bell`. Wiersz jest celem dotyku ≥ 44 px.
