Karta „Zostało na elastyczne”: duża kwota, pasek zużycia budżetu ze znacznikiem upływu miesiąca i zestawienie tempa.

`hero-amount` (Serif Display, 40–56 px) pokazuje, ile jeszcze można wydać; `div.flex-bar` ma wypełnienie `fill` (wydane) i kreskę `mark` (ile miesiąca minęło); przy przekroczeniu klasa `over` zmienia kolor wypełnienia na `neg`. `dl.kv.flex-kv` mówi, ile na dzień i czy jesteśmy w tempie. Ostrzeżenie `p.warn-note` prowadzi do kolejki „Do przejrzenia”.

- Konsument dostarcza kwoty, procenty (`style="width: …%"`) i adresy.
