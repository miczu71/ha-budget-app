Nawigacja miesiąca: link do poprzedniego miesiąca, tytuł ekranu `h1` i pusty slot po prawej.

Używaj na ekranach liczonych za miesiąc (Podsumowanie, Budżet, Wydatki). Link ma klasę `tap` (cel dotyku 44 px); pusty `span.month-link` trzyma tytuł na środku, gdy nie ma następnego miesiąca.

- Tytuł: Serif Display 26–34 px, waga 350.
- Konsument dostarcza nazwy miesięcy i adresy.
