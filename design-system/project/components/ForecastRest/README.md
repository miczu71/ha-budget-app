Rozwijana reszta zdarzeń prognozy (`details.fc-rest`) i kroki łączenia z bankiem (`ol.steps`, `div.link-box`).

`fc-rest` chowa mniej ważne zdarzenia pod „pozostałe (N)”; otwiera się samo, gdy wśród nich jest najniższy punkt. `ol.steps` to numerowane kroki procesu (Bank → Połącz bank); `div.link-box` pokazuje długi adres do skopiowania z zawijaniem znaków.
