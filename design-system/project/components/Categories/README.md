Kategorie: nazwa kategorii głównej i lista podkategorii rozwijanych (`details.leaf`) z edycją.

`form.rename.main` zmienia nazwę głównej. Każda podkategoria to wiersz `<details class="leaf">` z nazwą (`cat-name`) i podpisem; po rozwinięciu trzy formularze: zmiana nazwy, grupa budżetu (`form.move.group`: stałe / elastyczne / nieregularne) i przeniesienie (`form.move`). Cele dotyku ≥ 44 px, rozwijany wiersz nie zmienia układu listy.

- Zmiana grupy wpływa na pulę elastyczną w Budżecie.
