Komunikaty (`div.msg`) w wariantach `ok`, `warn`, `error`, wiersz świeżości danych (`p.fresh`) i pusty stan (`p.muted`).

`msg` to pasek z tłem `*-bg` i tekstem w kolorze znaczeniowym; błędy formularza dostają `role="alert"`. `p.fresh` mówi, kiedy dane zsynchronizowano. Pusty stan to jedno zdanie `muted` z podpowiedzią, co zrobić (nie sam napis „brak”).
