Lista reguł kategoryzacji: zakładki Reguły / Słownik sieci / Kategorie, przycisk nowej reguły i tabela `table.rules`.

`nav.tabs.rules-tabs` jest wspólna dla trzech ekranów. Tabela: warunki (link `cond-cell`, opcjonalnie nazwa i plakietka „wyłączona”), kategoria, trafienia (`num`) i akcje (`wyżej`, `niżej`, Włącz/Wyłącz, `Usuń` jako `secondary danger`). Wygrywa pierwsza pasująca reguła od góry listy. Pusta lista pokazuje zdanie z podpowiedzią, od czego zacząć.

- Na telefonie tabela zamienia się w karty (≤ 640 px).
