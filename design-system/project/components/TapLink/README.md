Linki: samodzielny z klasą `tap` oraz link w zdaniu.

Link samodzielny (poza zdaniem) dostaje klasę `tap`, żeby miał cel dotyku 44 px. Link w zdaniu ma obszar dotyku przez `::after` (lista selektorów w `app.css`), żeby wiersz tekstu nie rósł. Kolor linku to Ink z podkreśleniem; pomarańcz nie jest kolorem tekstu.
