Ekran Budżet: linia „Cykliczne”, karta puli elastycznej z formularzem kwoty, lista kategorii elastycznych i zestawienie „Poza pulą”.

`p.recurring-line` podsumowuje serie w miesiącu. Karta `flex-hero` ma tu formularz `form.rename` (pole kwoty i przycisk). `ul.flex-lines`: każda pozycja to link `tap`, kwota `cat-amount` i podpis z „zwykle” (mediana z 6 mies.). `dl.kv` pokazuje koszty stałe i nieregularne, które nie zmniejszają puli.

- Konsument dostarcza kwoty i adresy.
