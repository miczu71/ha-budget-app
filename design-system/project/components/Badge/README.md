Plakietki stanu (`.badge`) i chip kategorii (`.cat-chip`).

`.badge` ma warianty `ok`, `warn` i `error` (tło z tokenów `*-bg`, tekst w kolorze znaczeniowym). `.cat-chip` to przycisk-pigułka w wierszu transakcji: z kategorią (`span.src` pokazuje źródło) albo pusty (`empty`, przerywana ramka, kolor `warn`, „+ kategoria”).

- Kolor niesie znaczenie, nie dekorację: nie dawaj `warn` plakietkom neutralnym.
