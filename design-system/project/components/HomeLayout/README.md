Tryb edycji układu ekranu głównego: lista kafelków ze strzałkami ↑/↓ i okiem ukryj/pokaż.

`ul.layout-list` z wierszami `li.layout-row` (ukryty kafelek ma `off` i dopisek „(ukryty)”). Każda akcja to mały formularz z `button.secondary.layout-btn` (ikona SVG Lucide 20 px, `aria-label`); skrajne strzałki są wyłączone. Stopka `layout-foot`: „Przywróć domyślny” i „Gotowe”. Układ jest wspólny dla wszystkich urządzeń.
